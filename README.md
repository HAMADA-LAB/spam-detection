# SpamShield AI

A machine-learning web application that classifies text as **Spam** or **Ham**.

## Best model
Linear SVM

## Features
- TF-IDF text vectorization
- Unigrams and bigrams
- Naive Bayes, Logistic Regression, and Linear SVM comparison
- Best model selected using spam F1-score
- Interactive Streamlit web interface

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
